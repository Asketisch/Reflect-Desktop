安装 浏览文档

功能概览

三栏布局

左侧时间分桶会话列表（现在 / 今天 / 昨天 / 本周 / 更早），中间聊天区，右侧工具检查器 + 成本环形。

流式聊天

react-markdown + Shiki 代码块高亮；工具行折叠连续调用；思考增量在可折叠面板中。

输入器

自动增长文本框，/ 斜杠命令弹窗（47 条命令）、@ 文件引用、拖放图片附件、历史记录导航。

模态框套件

审批（工具 / 钩子 / 计划）、多问题 AskUser（带"其他"自定义文本）、自由文本 AskUser、计划就绪 Markdown 审查。

进程内后端

直接 Arc<AgentThread> 与 TUI/CLI 共享 —— 零序列化，各前端行为一致。

macOS 原生

悬浮标题栏 + 光泽效果、关闭到托盘、Dock 徽标、Cmd+. 中断、通过 tauri-plugin-global-shortcut 全局快捷键。

安装

从源码

git clone https://github.com/CNB/ReflectDesktop.git
cd ReflectDesktop
pnpm install
git submodule update --init --recursive
pnpm tauri build --bundles app
bash scripts/install.sh
# → /usr/local/bin/reflect-desktop
# → ~/Applications/ReflectDesktop.app

开发模式

pnpm tauri dev

平台专属说明见 README。

What's in the box

Three-pane layout

Time-bucketed session sidebar (Now / Today / Yesterday / This week / Older) on the left, chat in the middle, tool inspector + cost ring on the right.

Streaming chat

react-markdown + Shiki for code blocks; tool rows collapse consecutive calls; thinking deltas live in a collapsible panel.

Composer

Auto-grow textarea, / slash popup (47 commands from TUI), @ file mention, drag/drop image attachments, history navigation.

Modal suite

Approval (Tool / Hook / Plan), multi-question AskUser with "Other" custom text, free-text AskUser, Plan-Ready markdown review.

In-process backend

Direct Arc<AgentThread> sharing with TUI/CLI — zero serialization, identical behavior across frontends.

macOS-native

Overlay titlebar with vibrancy, close-to-tray, dock badge, Cmd+. interrupt, global hotkeys via tauri-plugin-global-shortcut.

Install

From source

git clone https://github.com/CNB/ReflectDesktop.git
cd ReflectDesktop
pnpm install
bash scripts/vendor-sync.sh /path/to/Reflect-Agent main
pnpm tauri build --bundles app
bash scripts/install.sh
# → /usr/local/bin/reflect-desktop
# → ~/Applications/ReflectDesktop.app

Dev mode

pnpm tauri dev

See README for platform-specific notes.
